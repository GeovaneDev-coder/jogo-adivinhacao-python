\# Jogo de Adivinhação em Python



Este é um projeto simples desenvolvido em Python com o objetivo de praticar lógica de programação e versionamento com Git/GitHub.



\## 🧠 Sobre o projeto

O programa gera um número aleatório e o jogador precisa tentar adivinhar qual é o número correto.



\## 🚀 Tecnologias utilizadas

\- Python 3
